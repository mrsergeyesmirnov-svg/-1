# Публичные тизеры для pulseteam.online

Скопировать в репозиторий `landing` (у cloud-агента нет write-доступа к public landing):

```bash
cp demo.html /path/to/landing/demo.html
cp -a demos /path/to/landing/
# применить patches/index-and-sitemap.patch или вручную правки FAQ/CTA
```

**Завеса:** на сайте — эффект и атмосфера. Полный SOP менеджера — только в `docs/onboarding-demos/` и в боте «📚 Материалы».
