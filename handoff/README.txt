Как открыть на iPhone (чтобы работали мокапы):

1. Скачай Kazna-KP.zip
2. «Файлы» → нажми архив → Разархивировать
3. Открой папку Kazna-KP
4. Нажми kp.html → Поделиться → Safari (важно: не оставляй во встроенном просмотрщике)
5. В КП: «Эскизы платформы» — переходы по мокапам работают

PDF: Kazna-KP.pdf — если нужна просто читалка без кликов по мокапам.
