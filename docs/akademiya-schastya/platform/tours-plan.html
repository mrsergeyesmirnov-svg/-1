Скоро: внутренний календарь

Не публичная афиша, а рабочий план команды: даты, состав ведущих, набор, бюджет.

  • Потоки: шефы / опердиректора / HR
  • Статусы: идея → набор → идёт → закрыт
  • Связка с CRM: кто из клиентов едет
  • Смета: площадка, еда, гонорары → в финансы

Публичная афиша остаётся на странице туров.
