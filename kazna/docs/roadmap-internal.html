Вывод по цене клиенту

100к / 450к — нормально

  • 100к таблицы — честно за 2–3 недели и живой контур
  • 450к платформа — ниже полного Финоко+внедрение сети и сильно ниже студии; выше «просто настроить календарь в SaaS»
  • Твоя маржа ~300–350к с платформы — ок, если scope не раздуть

Если торгуются

  • не резать ниже 80к таблицы / 400к платформа без урезания scope
  • торговать сроком и этапами, не «скидкой за всё»
  • кассы + автоиз iiko + планы года — ценность; без этого цена должна падать

2. Роадмап (для нас, не для КП)

0
Завтра — отправка КП
kp.html + ссылка на эскизы. Без роадмапа клиенту. Созвон: выбрать A или B, доступы iiko после аванса.
1
Неделя 1 — бриф и данные
Аванс 30%. Список организаций/счетов/касс. Одна тестовая выгрузка из iiko (остатки + накладная/оплата). Критерии приёмки на 1 странице. Договор с лимитом ответственности.
2
Недели 2–3 — если вариант A (таблицы)
Сводка «сейчас / сегодня / после» · календарь · заявки · автопометка оплачено где возможно · обучение 1 час · акт.
2
Недели 2–5 — если вариант B (платформа) MVP
Вход и роли · заявки + приоритеты · календарь · счета · простой экран касс · импорт iiko по крону · демо финдиру.
3
Недели 6–8 — платформа доводка
Планы (день/месяц/год) · перераспределение касс · автоархив по оплате iiko · права управляющих · 2 раунда правок · акт · поддержка с 40к/мес.
4
После запуска (опционально)
Стабилизация 1 месяц · кейс · разговор про совместные продажи % на другие сети.

3. План задач (чеклист разработки B)

Блок данные

  • подключить выгрузку/API iiko: счета, накладные, оплаты
  • маппинг организаций сети ↔ счета ↔ кассы точек
  • fallback: Excel/CSV если API тупит

Блок роли

  • логин управляющего / финдира
  • права на точки (настраивает финдир)
  • заявки: дата, сумма, приоритет; финдир может сменить приоритет
  • планы: дни недели, месяц, год

Блок деньги

  • виджеты сейчас / сегодня / после
  • календарь + перенос даты
  • кассы: норма / факт / перераспределение (учётная операция или заявка)
  • оплата в iiko → архив без галочки

Блок сдача

  • чеклист приёмки · акт · 14–30 дней гарантии по багам
  • не брать в v1: банк-автоплатёж, полная Сова, бухгалтерия

4. Риски по срокам (себе)

  • iiko — главный тормоз; закладывай +1–2 недели буфера
  • Кассы «можно ли перекинуть» — юридически/учётно уточнить у них, иначе только «сигнал», не проводка
  • Планы год — можно отдать во вторую очередь после MVP, если жмут срок

Источники ориентиров: сайты Финоко (комплект ресторана от 356к; настройка календаря 30–150к; подписка от ~80к/год), Adesk (прайс ~2–6к/мес), СоваРест (~3,5к/мес за объект). Цифры публичные витрины, у сети на месте часто выше.
