## Что вы хотите зафиксировать

Полноценное партнёрство **50/50 экономического интереса**, не «двое иногда делают вместе».

| | Смирнов (ты) | Ботвич |
|---|---|---|
| Доля в прибыли проекта | 50% | 50% |
| Роль | Управляющий товарищ: платформа Pulse Team, AI, сайт, упаковка, продажи, админка, финансы, масштабирование, продуктовая стратегия | Методология, экспертиза, консалтинг, обучение, менеджеры по счастью, качество результата |
| Часы | **Не** определяют долю | **Не** определяют долю |

Деньги: **выручка − согласованные расходы проекта = прибыль → 50/50.**  
Не «клиент заплатил 500к → сразу 250/250».

Клиенты пока платят **твоему ИП** — это оформляется как **ведение общих дел** тобой, а не как «все деньги твои».

## Юридическая оболочка на сейчас

**ИП + ИП → договор простого товарищества** (гл. 55 ГК РФ, ст. 1041–1054): совместная деятельность **без** нового юрлица.

В договоре обязательно:

1. Предмет: проект «Состояние смены» (консалтинг + цифровой контур).
2. Вклады и доли 50/50.
3. Ты — товарищ, ведущий общие дела и общий учёт.
4. Отдельный контур денег (счёт / субсчёт / учёт, не смешивать с Pulse «как личный SaaS» и прочими проектами).
5. IP: методика Ботвича / Pulse / бренд / клиенты / AI.
6. Решения **только единогласно**. Нет согласия одного — решения нет; продолжается рефлексия до компромисса. Так всегда. Сценарии выхода / deadlock **пока не прописываем**.

**Не скачивать шаблон из интернета и не подписывать вслепую.** Особенно из‑за налогов (ниже).

## НДС: как есть по НК, не «как на сайтах Pulse»

Сейчас на счетах Pulse / «Состояние смены»: **«Без НДС»** — это твой **личный** контур ИП.

Если появляется **простое товарищество**, включается **ст. 174.1 НК РФ**:

- Товарищество само не налогоплательщик.
- **Обязанности плательщика НДС** по операциям товарищества несёт товарищ, который **ведёт общий учёт** (это ты).
- Он выставляет счета-фактуры **от своего имени**, ведёт книги, сдаёт декларацию НДС по этим операциям.
- Вычет входного НДС по расходам товарищества — тоже у ведущего учёт, по счетам-фактурам **на его имя**.

### УСН 5% / 7% / освобождение по ст. 145 **сюда не спасают**

С 2025 у упрощенцев есть спецпорядок НДС (освобождение при лимитах ст. 145; ставки 5% и 7% — п. 8–9 ст. 164 НК).

**Минфин (письма 20.01.2025 № 03-07-11/3604, 22.05.2025 № 03-07-11/50136):**  
на операции **простого товарищества** этот спецпорядок **не распространяется**.

Практика комментариев 2025–2026: ведущий учёт (даже «упрощенец без НДС» или с 5/7%) по операциям товарищества считает НДС **по общим ставкам** (обычно 20% / 10% на дату операции — **ставку сверить с бухгалтером**, она менялась законодательно).

**Следствие для клиента:** счёт «Состояние смены» по товариществу, скорее всего, будет **с НДС**, а не «без НДС, как Pulse». Иначе схема учёта товарищества и витрина разъедутся.

НДС — **расход / обязательство деятельности**, его вычитают **до** дележа 50/50 (как налог, относящийся к совместным операциям). Как именно (из выручки, отдельной строкой) — прописать с бухгалтером.

## УСН: скрытый стоп-кран (важнее, чем «красивые 50/50»)

**п. 3 ст. 346.14 НК РФ:** участники договора простого товарищества на УСН обязаны применять объект **«доходы, уменьшенные на величину расходов»**.

Объект «доходы» (6%) для участника простого товарищества **запрещён**.

Если кто-то из вас сейчас на УСН «доходы» и подпишет договор в 2026:

- объект внутри года **нельзя** сменить (п. 2 ст. 346.14 — только с 1 января, уведомление до 31 декабря предыдущего года);
- риск: **потеря права на УСН с начала квартала**, в котором заключён договор (п. 4 ст. 346.13) → общий режим.

**До подписания бухгалтер обязан сказать:** какой объект УСН у Смирнова и у Ботвича **прямо сейчас**.

Если оба уже на «доходы−расходы» — путь проще.  
Если хотя бы один на «доходы» — **не подписывать ПТ в 2026**, либо сменить объект с **01.01.2027**, либо выбрать другую оболочку (ниже).

## Как считать деньги (операционка)

Ежемесячно одна таблица, которую видят оба:

```
Выручка проекта (оплаты клиентов за «Состояние смены»)
− согласованные расходы (подрядчики, реклама, сервисы, командировки, производство, комиссии)
− налоги и обязательные платежи, относящиеся к совместной деятельности (в т.ч. НДС товарищества)
= распределяемая прибыль
→ 50% тебе / 50% Ботвичу
```

Пример из вашей логики: 780к выручка − 180к расходы = 600к → по 300к.

Доля **не** зависит от того, кто больше часов кодил или вёл сессии. Отдельная оплата работы партнёра — только отдельным решением обоих.

**Правило решений (раздел 10 черновика):** любое новое решение по проекту принимается, только когда согласны оба. Если один не согласен — не продавливать, не «решающий голос», не принудительный выкуп. Обсуждение и рефлексия до компромисса, который принимают оба. Так всегда. Молчание ≠ согласие. Уже согласованные операции (счёт, расход из перечня) Управляющий товарищ делает сам, пока не меняется суть решения.

## Куда смотреть на горизонте года (до ~лета 2027)

| Срок | Что делать |
|---|---|
| **Сейчас, до любой подписи** | Бухгалтер: режимы обоих ИП, НДС, объект УСН. Юрист: этот черновик + IP. |
| **Пока режимы не стыкуются** | Не ПТ. Временная связка: ты — договор с клиентом; Ботвич — договор подряда/возмездных услуг с тобой; внутренний memo 50/50 **не заменяет** налог. |
| **Если ПТ можно** | Отдельный счёт/учёт; счета клиентам по правилам 174.1; ежемесячный отчёт; смена текстов «без НДС» на витрине проекта. |
| **Выручка растёт, 2+ точки, наём** | Смотреть **ООО** (два участника 50/50) или ИП+ООО. Проще нанимать, продавать долю, не тащить НДС товарищества на личное ИП. |
| **Pulse отдельно живёт как SaaS** | Юридически не смешивать подписку Pulse «как есть» и выручку консалт-проекта, пока не решите, что Pulse *в этом бренде* — вклад в товарищество (лицензия). |

Итог на год: **не менять ОПФ сразу**, но и **не делать вид, что «просто 50/50 на словах»**. Либо корректное ПТ после проверки УСН, либо подряд + прозрачный отчёт до 01.01.2027, либо ООО, когда пойдёт живая выручка.
