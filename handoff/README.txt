Как открыть на iPhone (чтобы работали мокапы):

1. Скачай Kazna-KP.zip
2. В «Файлы» нажми на архив → «Разархивировать»
3. Открой папку Kazna-KP → kp.html
4. Если откроется как текст: «Поделиться» → Safari / Chrome
5. В КП жми «Эскизы платформы» — переходы внутри preview работают

Не открывай kp.html прямо из Telegram без распаковки — ссылки на мокапы сломаются.
