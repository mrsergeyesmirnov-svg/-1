# AI-советник: наставник для управляющего

Pulse получает оценки смен, проблемы и комментарии от команды.
AI-советник берёт эти данные и пишет управляющему не просто «что плохо»,
а что с этим делать и как поговорить с человеком.

## Опрос смены (как отвечает линия)

1. **Как прошла смена?** — эмоция (в отчёты уходит числом):
   - 🔥 Заряженная → 5
   - 🙂 Нормальная → 4
   - 😐 Так себе → 2
   - 🥶 Тяжёлая → 1
2. **Что мешало работать?** — один выбор: Команда / Кухня / Гости / Процессы / Моё состояние / Нигде.
3. **Расскажите подробнее** — текст или **голосовое** (Whisper через тот же OPENAI_API_KEY).

## Как работает советник

**Автоматически.** Когда порог сигнала пробит и менеджеру уходит push-алерт,
следом в ту же личку приходит AI-совет.

**Раз в неделю (воскресенье 20:00).** Итог недели по точке — если есть сигналы.

## Стоимость

~$2/месяц при 200 советах (GPT-4o-mini) + копейки за Whisper на голос.
Можно переключить на GPT-4o: `OPENAI_MODEL=gpt-4o`.

## Подключение

1. [platform.openai.com](https://platform.openai.com) → API keys → Create secret key
   (Owned by: You, Permissions: All).
2. **Add credits** — без баланса ключ не работает ($5–10 хватит надолго).
3. Railway → Variables:
   ```
   OPENAI_API_KEY=sk-proj-ваш-ключ
   ```
4. Redeploy.

Если ключа нет — опрос смены работает, AI-советы и расшифровка голоса выключены.

## Что советник не видит

Имена и Telegram ID. Только цифры, темы и анонимные цитаты.
