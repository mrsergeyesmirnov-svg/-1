# HoReCa ecosystem demo

Интерактивный прототип новой экосистемы вокруг «Состояния смены».

## Что можно потыкать
- Роли: сотрудник / ресторан / эксперт / организатор
- Дневник смен и check-in
- Работа, подработки, события и обучение
- Кружки и профессиональное сообщество
- Профессиональный диалог сотрудника и ресторана
- Внутренний мэтч без публичных рейтингов
- Анонимная командная аналитика
- Подбор экспертов под задачи ресторана

Это UX-прототип на статических данных. Он не подключён к production-БД и не изменяет Telegram-бот.
