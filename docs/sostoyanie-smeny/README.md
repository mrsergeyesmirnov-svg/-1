# Состояние смены — сайт

Проект **Академии счастья** (не сам бренд дома). Витрина консалтинга + цифрового контура.

Дом: `../akademiya-schastya/`.

## Страницы

| Файл | Назначение |
|---|---|
| `index.html` | Лендинг: миссия, путь, 4 блока, продукт |
| `privacy.html` | Политика конфиденциальности |
| `oferta.html` | Оферта + реквизиты ИП Смирнова |
| `audit.html` | Аудит-калькулятор (пароль) → печать счёта/акта |
| `site.css` | Стили (база PulseTeam + аудит) |

## Калькулятор

- URL: `audit.html`
- Пароль по умолчанию: `smena2026`
- Считает часы по матрице S–XL × коэффициенты → цена
- Кнопки: печать счёта, печать акта, копировать КП

Смена пароля: в `audit.html` замените строку `sha256("smena2026")` на свой пароль.

## Локально

Откройте `index.html` в браузере или:

```bash
cd docs/sostoyanie-smeny && python3 -m http.server 8766
```
