# AI-наставник управляющего

Бот читает **реальные комментарии** персонала (текст и голос) и через OpenAI
пишет управу: тенденция → риск → действия → вопросы тет-а-тет.
Темы: команда, кухня, гости, процессы, состояние.

## Важно

Советы наставника — **только OpenAI**, не шаблоны.
Нужен `OPENAI_API_KEY` в Railway. Без ключа тренд в «Горящих» поднимется,
но текста наставника не будет (админу уйдёт напоминание про ключ).

На карточке горящего вопроса и в пуше — кнопка **«🤖 Совет наставника»**:
по запросу OpenAI разбирает комментарии по этой теме.

## Как срабатывает

1. ≥3 одинаковых кнопки «что мешало» **или** ≥3 похожих текста
   (ключевые слова + при наличии ключа — LLM-разбор).
2. Горящая тенденция в личку + разбор комментариев GPT.
3. Воскресенье 20:00 — итог недели (только с ключом).

## Опрос

Эмоция → фактор → комментарий/голос.
При «🔥 Заряженная»: «Что сделало смену такой?» (без «всё хорошо»).

## Подключение

Railway → Variables → `OPENAI_API_KEY=sk-proj-...` → Redeploy + баланс OpenAI.
Опционально: `OPENAI_MODEL=gpt-4o-mini` (по умолчанию).
